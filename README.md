Islamic Banking Insights
منصة استبيان أكاديمي لدراسة واقع وتحديات تحول البنوك التقليدية إلى الصيرفة الإسلامية في موريتانيا.
يوفر المشروع واجهة استبيان للمشاركين، ولوحة تحكم للباحث لمراجعة الاستجابات وتحليلها وإدارتها.
